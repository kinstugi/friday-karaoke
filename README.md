# Friday Karaoke

Private karaoke queue application for school Friday karaoke nights.

Hosts create a session, students scan a QR code, add songs via YouTube URLs, and
the queue runs with the host's browser as the playback device.

See `docs/PROJECT_BRAIN.md` for the authoritative project context.

## Development

Work happens on the `dev` branch. `master` only receives merged, reviewed PRs.

See `docs/RUNBOOK.md` for local development commands.
